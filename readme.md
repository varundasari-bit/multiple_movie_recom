## Dataset

This project requires the Movie dataset to run the recommendation system.

The dataset is not included in this repository due to its size and/or redistribution restrictions.

### Setup

1. Download the dataset from the original source: **[Insert dataset download link]**
2. Extract the downloaded files if they are compressed.
3. Place the dataset in the project directory using the following structure:

```text
project/
├── app.py
├── recommender.py
├── requirements.txt
├── README.md
└── movies.csv/        # Download separately
```

4. Install dependencies:

```bash
pip install -r requirements.txt
```

5. Run the application:

```bash
python app.py
```

> The application requires the dataset to be downloaded and placed locally before running.
